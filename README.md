# dsh-user-status

让 DSH 里的助手知道你现在在电脑上做什么——前台窗口、空闲了多久、QQ音乐在放什么。

## 功能

- **每轮带上当前状态**：前台程序、空闲秒数、QQ音乐在放的歌，模型每轮都能看到
- **侧栏状态点**：左下角一个小圆点，绿 = 在用、黄 = 挂机（5 分钟没操作）、灰 = 读不到
- **点开看详情**：前台程序、空闲多久、歌名歌手
- **应用记录**：记录最近几天各应用的时长和时段，存在本机
- **隐私打码**：QQ、微信、密码管理器、银行页面等只显示应用名，不显示窗口标题
- **友好名称**：常见进程会显示成 DSH、Edge、文件管理器、VS Code 等

## 安装

在 DSH 的插件管理器里装入本包目录或 `.tgz`：

```bash
dsh plugin install ./dsh-user-status-1.4.0.tgz
```

## 使用

1. 装好后刷新页面
2. 左侧栏最下面、设置按钮旁边出现一个小圆点
3. 点一下展开当前状态
4. 进「设置 → 用户状态」可以调：
   - **记录天数**：保留最近多久（1~30 天）
   - **历史记录**：不读 / 只读摘要 / 读完整明细

### 历史记录和 token

- **不读**：不花 token
- **只读摘要**：每轮多一句「最近 N 天常用：Edge 5h、DSH 3h…」，约 30 token
- **读完整明细**：按天列出用过哪些应用，每轮几千到上万 token

注意这部分**每轮都会带上**，不是查一次就结束，对话越长累积越多。

## 说明

- 仅支持 **Windows**：窗口和 QQ音乐标题都靠 Windows 接口读取
- 音乐只认 **QQ音乐**（读它正在播放的窗口标题）
- 状态只在本机、只给模型看，不会主动发到群里
- 记录存在系统临时目录（`%TEMP%\dsh-user-status-history.json`），卸载后没清干净可以手动删

## 隐私

以下程序在前台时标题不会上报，只显示应用名：

QQ、微信、TIM、Telegram、Discord、飞书、钉钉、Slack、Outlook、Foxmail、1Password、Bitwarden、KeePass、LastPass

标题里出现「密码、验证码、银行、身份证、支付、无痕」等词的，同样打码。
