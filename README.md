# dsh-user-status

让大肥鱼（你的 DSH 助手）知道你现在在电脑上做什么。

## 它做什么

- 每轮对话把「前台窗口 / 空闲时长 / QQ音乐在放什么」带给模型
- 左侧栏底部一个小圆点，一眼看出你在用、挂机还是不在
- 点开看详情：前台程序、空闲多久、歌名歌手
- 隐私程序（QQ、微信、密码管理器、银行页面等）只显示应用名，不显示窗口标题
- 记录最近几天用过哪些应用、各用了多久（设置页可看，也可以选择读给模型）

## 安装

在 DSH 的插件管理器里，把本包目录（或 `.tgz` 包）装进去即可。

```bash
# 示例：用 DSH 的插件管理命令
dsh plugin install ./dsh-user-status-1.4.0.tgz
```

或者直接把解压后的目录交给插件管理器安装。

## 使用

1. 装好后刷新页面
2. 左侧栏最下面、设置按钮旁边会出现一个小圆点
3. 点一下展开详情
4. 设置 → 用户状态 里可以调记录天数、历史记录要不要读给模型

## 说明

- 仅支持 **Windows**：窗口和 QQ音乐标题都靠 Windows 接口读取
- 音乐只认 **QQ音乐**（读取它正在播放的窗口标题）
- 状态只在本机、只给模型看，不会主动发到群里

## 隐私

以下程序在前台时，标题不会上报，只显示应用名：

QQ、微信、TIM、Telegram、Discord、飞书、钉钉、Slack、Outlook、Foxmail、1Password、Bitwarden、KeePass、LastPass

标题里出现「密码、验证码、银行、身份证、支付、无痕」等词的，同样打码。
